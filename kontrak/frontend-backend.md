---

## 2. Prinsip Pengembangan

1. Sederhana tetapi rapi.
2. Konsisten dalam struktur folder.
3. Menggunakan Bootstrap untuk tampilan.
4. Menggunakan PHP Native tanpa framework.
5. Menggunakan MySQL sebagai database.
6. Menggunakan session untuk login.
7. Menggunakan role untuk pembatasan akses.
8. Menggunakan validasi input pada setiap form.
9. Menggunakan prepared statement pada proses penting.
10. Memisahkan query database, proses bisnis, dan tampilan.

---

## 3. Ruang Lingkup Teknis

1. Struktur folder aplikasi.
2. Layout utama aplikasi.
3. Standar tampilan halaman.
4. Standar proses CRUD.
5. Standar autentikasi dan session.
6. Standar perhitungan AHP.
7. Standar ranking dan laporan.
